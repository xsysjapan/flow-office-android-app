# Android UIデザインシステム

## 目標

受付や入口で反復利用される業務端末として、低装飾、高判読性、大きな操作面、明確な状態通知を
優先する。品質をグラデーションや影ではなく、情報階層、余白、整列、タイポグラフィ、状態の
区別、予測可能な操作で作る。

作業前に`CLAUDE.md`と`docs/android-punch-reader-design.md`のUI・状態・セキュリティ章を読む。

## デザイン前に整理する

実装前に次を短く書き出す。

1. 画面の目的
2. 主要ユーザーと利用環境
3. 最重要操作
4. 情報の優先順位
5. レイアウト構造
6. 再利用するMaterial 3／既存コンポーネント
7. phone、tablet、縦、横の差
8. Loading、Offline、Error、Disabled等の状態
9. アクセシビリティ上の判断

## 視覚原則

- 主要操作と現在状態を一目で理解できるようにする。
- 1画面に強い視覚的主役を1つだけ作る。
- すべてをCardで囲わず、余白と見出しでグループ化する。
- Material 3標準部品があれば独自部品を作らない。
- 色、寸法、文字スタイル、shapeをThemeへ集約する。
- 4dpグリッドを使い、主要余白を8 / 12 / 16 / 24 / 32dpから選ぶ。
- 最小タップ領域を48dp、打刻ボタンを原則56dp以上にする。
- 本文を14〜16sp、主要ラベルを16〜20spを基準にする。
- 強い影、不要なアニメーション、原色の多用を避ける。
- ライト／ダーク双方でsemantic colorと十分なコントラストを使う。

## 打刻画面のルール

- 4種の打刻ボタンに日本語ラベルと意味のあるアイコンを付ける。
- 選択状態を色だけで表さず、枠、アイコン、テキスト、semantics `selected`を組み合わせる。
- 時計、端末名、通信状態、未送信件数を主操作より弱い階層に置く。
- 「社員証をかざしてください」とNFC待受状態を画面の中心的な案内にする。
- NFC無効／非対応では、理由と次の操作を表示する。
- 連続利用で前の社員名が残らないよう、結果表示を2〜3秒で閉じる。

## 結果状態を混同しない

| 状態 | 表現 |
|---|---|
| サーバー成功 | 打刻種別、時刻、成功文。色＋アイコン＋文字＋任意の音／振動 |
| オフライン保存 | 「端末に保存」「復旧後に送信」。成功チェックだけを使わない |
| 再試行可能 | データが端末に残っていることと自動再送を説明 |
| 恒久失敗 | 次の行動を明記。例: カード登録を管理者へ依頼 |
| 401 | 端末認証無効、管理者確認、再ペアリングを明記 |

## アクセシビリティ

- アイコンだけの操作へcontent descriptionを付ける。
- 状態へ標準semantics（selected、disabled、role）を使う。
- 時計の毎秒更新をlive regionにしない。
- 結果通知は重複読み上げを避けて一度だけ通知する。
- font scale 2.0、TalkBack、キーボード／Switch Accessを考慮する。
- 色、音、振動の単独表現を禁止する。
- 48dp未満のタップ領域を作らない。

## 禁止事項

- 生の16進色や画面固有の場当たり的なdp/sp
- 不要なグラデーション、強い影、ガラス表現
- 巨大見出し、キャッチコピー、意味のない中央揃え
- すべての情報をCard化する
- 絵文字をアイコンとして使う
- 技術的な例外文、API URL、stack traceを利用者へ表示する
- 成功とオフライン保存へ同じ見た目・文言を使う
- token、pairing code、完全なNFC UIDをPreviewやfixtureへ含める

## Previewマトリクス

画面または主要コンポーネントごとに必要なPreviewを用意する。

- Light / Dark
- Idle / Processing / Success
- Offline / Retryable / Permanent Error / Authentication Invalid
- 長い端末名・長いエラー
- 大きなfont scale
- phone portrait / tablet / 必要ならlandscape

Preview用データには架空の値を使い、tokenや実在する認証キーを含めない。

## 実装後の視覚QA

- [ ] 最重要操作が説明なしで分かる
- [ ] 情報階層と整列が一貫している
- [ ] 同じ意味の部品が同じ外観・挙動である
- [ ] 成功、端末保存、失敗、401を離れた位置から区別できる
- [ ] Light / Darkでコントラストと状態色が破綻しない
- [ ] phone / tablet / 横向きで切れない
- [ ] font scale 2.0で主要操作が隠れない
- [ ] TalkBackで操作名、選択、無効、結果を理解できる
- [ ] loadingで大きなレイアウトシフトが起きない
- [ ] 個人名が必要以上に長く残らない
- [ ] 不要なCard、影、枠線、説明文、装飾がない

ビルド成功だけで完了にせず、Preview、スクリーンショット、エミュレータのいずれかで実際の描画を
確認する。問題を見つけたらThemeまたは共通コンポーネントで直せないか先に検討する。
